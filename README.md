# Trader-Performance-vs-Market-Sentiment
# Hyperliquid Trader Behavior Analysis Using Bitcoin Fear & Greed Sentiment

## Project Overview

This project analyzes the relationship between Bitcoin market sentiment and trader behavior on Hyperliquid.

The analysis combines:

1. Bitcoin Fear & Greed Index dataset
2. Hyperliquid historical trader dataset

The objective is to determine whether market sentiment influences trader profitability, trading activity, position sizing, and overall behavior.

---

## Files

* `Hyperliquid_Analysis.ipynb` – Main notebook
* `README.md` – Project documentation
* Output charts generated in notebook

---

## Setup

Install required libraries:

```bash
pip install pandas numpy matplotlib
```

---

## Running the Project

1. Open the notebook in Google Colab or Jupyter Notebook.
2. Run all cells sequentially.
3. The notebook will:

   * Load datasets
   * Clean and merge data
   * Generate metrics
   * Perform sentiment analysis
   * Create visualizations
   * Produce trader segment analysis

---

## Key Metrics

* Daily PnL
* Win Rate
* Average Position Size
* Trade Frequency
* Long/Short Ratio

---

## Trader Segments

* Frequent vs Infrequent Traders
* Consistent Winners vs Inconsistent Traders
